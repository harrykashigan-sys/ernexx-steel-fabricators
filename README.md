## 🏗️ About Ernexx Steel Fabricators

Ernexx Steel Fabricators is a leading metal construction company based along the Mombasa Road / Syokimau industrial corridor in Nairobi, Kenya. We specialize in heavy structural steel warehouse framing, bespoke architectural laser-cut entrance gates, solar-tinted glass canopies, helical spiral staircases, marine-grade SS316 balustrades, and elevated industrial tank towers.

## ⚡ Key Features

- **Multi-Page Architecture:** Dedicated routes for Overview, Capabilities, Ground Projects, Material Tonnage Configurator, Steel & Aluminum Specifications, Nairobi Workshop Hub, Technical Engineering Blog, FAQ, and Contact RFQ Portal.
- **Interactive Tonnage & Turnaround Specifier:** Calculate structural metal mass, recommended section profiles, deflection tolerances, and shop lead times.
- **Interactive Multi-Project Before/After Progression Slider:** Real on-site inspection transitions from raw steel framing to completed glazed architectural canopies and warehouses.
- **SEO & Google Search Optimized:** Full Schema.org JSON-LD structured data (`GeneralContractor`), OpenGraph tags, semantic hierarchy, and targeted keywords for Kenyan construction queries.
- **High Performance:** Progressive-plane compressed images (~200KB each), responsive layouts, and zero bloat.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/harrykashigan-sys/ernexx-steel-fabricators.git
cd ernexx-steel-fabricators

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
